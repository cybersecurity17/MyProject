\# Cisco Packet Tracer Networking Projects



\## About

This repository contains networking assignments created using Cisco Packet Tracer as part of my Network and Cyber Security studies.



\## Projects



\### Unit 3: Configure DNS Server and Web Server

\- Create a network topology using PCs, a switch, DNS server, and web server.

\- Configure IP addresses for network devices.

\- Configure DNS records to map a domain name to the web server.

\- Enable HTTP service on the web server.

\- Test network connectivity and access the website.



\*\*Project File:\*\* `Cisco\_Packet\_Tracer/Unit\_3\_DNS\_Web\_Server.pkt`



\### Unit 4: Configure DHCP Server

\- Create a network topology using PCs, a switch, and DHCP server.

\- Configure a static IP address for the DHCP server.

\- Configure DHCP address pool, subnet mask, default gateway, and DNS server.

\- Assign IP addresses automatically to PCs.

\- Verify network connectivity using ping.



\*\*Project File:\*\* `Cisco\_Packet\_Tracer/Unit\_4\_DHCP\_Server.pkt`
